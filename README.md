# MACROARSENAL — studio

Fabrication du film de présentation de l'assistant MACROARSENAL : voix, musique et contrôles automatiques.
Tout tourne sur les serveurs de GitHub (dépôt public : minutes de calcul gratuites).

- `voix/` : voix du conteur, créées à partir d'une description (Qwen3-TTS, Alibaba, licence Apache-2.0 :
  gratuit, usage commercial permis ; aucune voix de personne réelle imitée), puis contrôlées par transcription.
- Les images du film sont calculées à part ; le site est dans un dépôt privé.
